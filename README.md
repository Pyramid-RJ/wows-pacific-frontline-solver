# 太平洋战线 · 最优解求解器

> **当前版本 v0.3**（2026-10-14）· 本次改了什么见 [`doc/更新说明.md`](doc/更新说明.md)

《战舰世界》「太平洋战线」小游戏的最优解求解器。

把每个据点的**游戏截图**交给它，它会算出该据点的**推荐编队、变项装配与预期胜率**；
也可以一次投入整局全部截图，程序按阶段自动逐关求解。目标是让你**稳稳通关**。

全程不需要写代码 —— 装好环境后，日常就是「截图 → 拖进批处理 → 看结果」。

---

## 快速开始

前提：Windows 10 / 11，装有 [Python 3.10+](https://www.python.org/downloads/)
（安装时勾选 **Add python.exe to PATH**）。

1. **装环境（每台电脑一次）** —— 双击 `安装环境.bat`，自动创建虚拟环境并安装依赖
   （约 100MB，含 OCR 引擎，只需联网这一次）。
2. **求解** —— 截好据点截图，把**文件夹拖到 `求解整局.bat` 上**；
   程序自动按阶段分组、逐阶段求解。
3. **看方案** —— 求解完自动打开图形面板；之后随时双击 `查看面板.bat` 再看。

> **第一次使用前，请先双击 `编写输入.bat`** —— 卡牌默认按「全部拥有」处理，
> 把你**自己没有的卡取消勾选**、填上战损格数与当前阶段即可。

## 截图怎么截

- 每个据点的地图 / 部署界面截一张图，全部放进同一个文件夹。
- **游戏窗口** 1920×1080 及以上最佳（决定识别清晰度的是**游戏窗口**，不是截图文件大小）；
  低于 1080p 也能用，但条件小字与工具栏角标请对照游戏人工核对。
- 截图**必须包含**：敌方卡牌、中部部署区、**底部整条「变项工具栏」**、右侧面板；
  **不要**把我方卡组栏截进去（会干扰库存识别）。
- 等「保存成功」之类弹窗消失、据点处于可操作状态后再截。

更细的截图要求与常见翻车点见 **[使用说明.md](使用说明.md)**。

## 它会输出什么

- 每个据点一张卡：敌方战力 / 弱点 → **推荐编队**（每个位置的卡、有效参数、胜率）
  → **变项装配**；
- `✓ 绿色` = 达到目标胜率（默认 100%），`✗ / !` = 未达标并附原因；
- 底部汇总：本阶段参战卡、次级代币用量、进度代币收益、留存的高战力卡；
- 结构化结果同时写入 `data/plan.json`，供图形面板读取。

## 目录结构

```
安装环境.bat      一次性安装依赖
编写输入.bat      告诉程序你有哪些卡、战损与阶段
求解整局.bat      整局求解（推荐）
求解单阶段.bat    只求解一个阶段
查看面板.bat      打开图形面板

code/             识别与求解程序
data/             卡池、图标/字形模板、变项配置等数据
doc/              规则手册与配图
examples/         样例输入与期望输出
使用说明.md        完整使用文档
requirements.txt  依赖清单（安装脚本会自动读取）
```
