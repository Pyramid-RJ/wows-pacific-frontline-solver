## 一、行动总览

“太平洋战线”让您统率一支海军部队，投入灵感源自历史的行动并获取奖励。每个行动分为数个阶段，其中包含需通过战斗攻克的关键据点。行动难度各异，取决于其关键据点、战斗时长与战斗条件。**每天开放三个行动。**

| 层级 | 说明 |
| --- | --- |
| 行动 Action | 一天的挑战单位，每天开放 3 个；内部含若干阶段 |
| 阶段 Stage | 行动的顺序推进单位，只能攻克当前阶段的关键据点，无法回退 |
| 关键据点 Key Point | 阶段内的具体节点，含敌方单位、奖励与战斗条件；难度各异 |
| 敌方单位 | 据点内的战斗对象，有固定战力值与至多 2 项弱点 |
| 我方单位 | 每个单位在每个阶段只能部署至一个关键据点，共 3 格生命值 |

### 结束行动的三种方式

当您完成最终阶段、放弃或重新开始行动时，该行动即告结束。

| 结束方式 | 结算结果 |
| --- | --- |
| **完成行动** | 保留全部已获奖励 + 完成奖励；摧毁所有敌方单位可额外获得“完美完成”奖励 |
| **放弃行动** | 保留至今获得的所有奖励，但不含额外奖励 |
| **重新开始** | 移除该次已获得的所有奖励、单位与变项，并重置本次行动中消耗的单位与变项 |

## 二、行动流程

| 步骤 | 操作 |
| --- | --- |
| 1 | 选择行动（每天 3 个） |
| 2 | 进入阶段，查看该阶段的关键据点 |
| 3 | 选择关键据点，查看敌方单位、奖励与战斗条件 |
| 4 | 确认敌方弱点与敌方战力，判断胜算 |
| 5 | 编排队列：配置增益方向、减益位置、变项栏位 |
| 6 | 参战：双方按总战力区间对比判定结果，我方单位损 1 格生命值 |
| 7 | 达成阶段目标数量 → 推进下一阶段；无法回退 |
| 8 | 最终阶段需连同主要目标一并摧毁 → 行动完成 |

## 三、阶段与阶段目标

每个行动分为数个依序进行的阶段。您只能攻克目前阶段的关键据点；**一旦推进至下个阶段，便无法返回先前的阶段。** 每个阶段都让您更接近行动的最终目标。

每个阶段中，您都需要摧毁特定数量的敌方单位以完成目标。您不必摧毁所有敌方单位，但这么做可获得额外奖励，并提高在后续阶段中的胜算。

| 阶段类型 | 目标要求 |
| --- | --- |
| **中间阶段** | 摧毁特定数量敌方单位即可完成；超出数量可获额外奖励，并提高后续阶段胜算 |
| **最终阶段** | 需摧毁主要目标（强大敌方单位），且必须连同其他敌方单位一并摧毁 |

### 阶段面板字段说明

![阶段面板]figures/ans_stage_panel.png)

进入阶段后，右侧面板自上而下依次展示：

| 面板元素 | 含义 |
| --- | --- |
| **阶段 1 · 进行中** | 阶段序号与当前状态（进行中 / 已完成） |
| **阶段目标：摧毁 5 个单位** | 本阶段需摧毁的敌方单位数量；超出可获额外奖励并提高后续胜算 |
| **1 / 2 标签** | 关键据点切换页签，数字为据点编号，星数为难度（★★ 普通，★ 较低） |
| **战斗条件 · 全域** | 当前据点生效的战斗条件类型（全域 / 指定 / 区域） |
| **每摧毁一个敌方单位可移除 4% 的战斗条件** | 条件移除进度：全域 4%/单位，指定 25%/单位 |
| **敌方战力：驱逐舰 +16%** | 条件带来的敌方战力加成（按舰种生效） |
| **敌方单位 12 / 13 / 12 / 1** | 该据点敌方单位的数量与各自可用数量角标 |

## 四、关键据点

每个阶段包含数个关键据点，每个据点都各自有敌方单位、奖励与战斗条件。虽然您不必攻克阶段中的所有关键据点，但您可以根据风险、奖励与对后续战局的影响来取舍。**关键据点难度各不相同，取决于敌方单位的强度。**

---

## 五、您的舰队

每个单位在每个阶段只能部署至一个关键据点。单位每次参与战斗都会损失生命值，并将剩余生命值带入该行动后续的所有阶段。

| 要点 | 说明 |
| --- | --- |
| **部署限制** | 每个单位在每个阶段只能部署至一个关键据点 |
| **生命值累积** | 单位每次参战损失生命值，剩余生命值带入本行动后续所有阶段（不单独重置） |
| **集中 vs 分散** | 集中最强单位可提高单点胜率；分散部署调度更灵活、更易拿到额外奖励 |
| **阶段内单次参战** | 一张卡牌在该阶段的另一场战斗中被使用后，本阶段内其他战斗均无法再参战 |

> **注意**：「阶段内单次参战」限制的是**单位本体**，不影响增益/减益等效果能否使用 —— 即已参战的卡牌，其提供的增益效果仍可继续作用于其他战斗。

> **战术含义**：这是「集中 vs 分散」抉择的硬性约束。一个阶段有 N 场战斗时，可参战的单位数上限为 N —— 想用同一张卡打两场是不可能的，必须按战斗场数准备足够的单位。

![关键据点 2 战斗部署]figures/ans_kp2_battle.png)

> 「**已排派 于关键据点1**」= 该卡已在本阶段的前一场战斗中使用过，按规则本阶段内不可再参战。但其提供的增益效果不受此限制，仍可继续使用。

> **取舍要点**：将最强单位集中投入单一关键据点，或许能提高胜率；但将舰队分散至多个据点，则能让您在调度上更灵活，也更有机会获得额外奖励。

## 六、单位生命值

每个单位都有**三格生命值**。单位每次参与战斗便会损失一格生命值。生命值越低，单位的参数越差，总战力也随之下降。

| 剩余生命值 | 参数与可用性 |
| --- | --- |
| 3 格生命值 | 100% 参数 |
| 2 格生命值 | 90% 参数 |
| 1 格生命值 | 80% 参数 |
| 0 格生命值 | 无法部署 |

---

## 七、总战力

总战力是战斗中的主要数值，由**火力 + 存活性 + 机动性**三项参数相加，再计入**正负 10 点**的浮动数值后得出。总战力也会受到其他我方单位增益效果，以及该单位目前生命值的影响。

> **实战对照**：以「USS 拉菲」为例，卡面三项数值为 火力 55 / 生存 60 / 机动 65，合计 180 点，卡面显示的总战力区间即为 **170–190**（180 ± 10）。

---

## 八、敌方战力

每个敌方单位都有**固定的战力值**（不带浮动区间，以红色显示）。

> **关键：胜率的本质是一个概率**
> 我方总战力是**波动的**（浮动区间），敌方战力是**确定的**（固定值）。战斗时会先在我方区间内**随机**取一个值，再与敌方固定值比较 —— 所以胜率是概率，而不是必然结果。

| 战力对比 | 战斗结果 |
| --- | --- |
| 我方总战力 > 敌方战力 | 胜率随差距增大而提升 |
| 敌方战力 > 我方总战力 | 不可能获胜 |
| 敌方战力 < 我方总战力 | 必定获胜 |

![胜率标注实例]figures/enemy_examples.png)

### 胜率计算方式

**胜率 = 我方区间中「大于等于敌方战力」的取值数 ÷ 区间总档数**

以截图中的三例验证：

| 对战组合 | 胜出档数 | 理论值 | 界面显示 |
| --- | --- | --- | --- |
| 德·鲁伊特 83–103 vs 岸防炮 91 | 13 / 21 | 61.9% | **62%** |
| 法拉格特 88–108 vs 岸防炮 91 | 18 / 21 | 85.7% | **86%** |
| HMS反击 105–125 vs 吹雪级 105 | 21 / 21 | 100% | **100%** |

> 第一例说明：区间 83–103 共 21 档，敌方 91，则满足「≥91」的是 91–103 共 13 档，13 ÷ 21 ≈ 61.9%，界面四舍五入显示 62%。三个案例全部精确吻合，公式成立。

善用增益效果，或以减益效果针对敌方弱点，来提高胜率。

## 九、弱点

每个敌方单位**最多有两项弱点**：防空火力、烟幕、被侦察性、大口径、速射、攻击机。不同敌方单位弱点各异，务必在战斗前先行确认，以便选择减益效果最有效的单位。

### 弱点类型一览

| 弱点 | 对应舰船能力 | 减益效果说明 |
| --- | --- | --- |
| **防空火力** | 对空作战能力相关 | 敌方单位无法对被指派的目标造成伤害 |
| **烟幕** | 掩护/遮蔽能力相关 | 敌方单位无法对藏身烟幕的目标造成伤害 |
| **被侦察性** | 隐蔽与雷达探测相关 | — |
| **大口径** | 大口径主炮相关 | — |
| **速射** | 速射副炮相关 | — |
| **攻击机** | 舰载机攻击相关 | — |

### 弱点命中次数与减益叠加（核心机制）

![弱点与减益叠加机制]figures/ans_weakness_tooltip.png)

- 敌方单位**最多有 2 个弱点**。
- **每个弱点最多可被命中 3 次**。
- **第 3 次命中后达到最低值 −60%**（即单条弱点最多削减 60%）。
- **不同弱点被命中时，减益加算**。

### 减益总上限（受方向数限制）

由于我方所有舰船对**一个方向最多只能施加一个减益**，实际总减益有上限：

| 配置 | 减益上限 | 构成 |
| --- | --- | --- |
| **不使用增益** | **最多 −60%** | 一个减益打满 3 级（−60%） |
| **使用增益** | **最多 −100%** | 同时挂 1 个 3 级（−60%）+ 1 个 2 级（−40%） |

> 也就是说：**−120% 的理论上限在实战中无法达到**。「特化训练」（特殊变项，减益效果 ×2）是实现 −100% 的关键 —— 它让同一单位可同时施加两个减益。

## 十、卡牌特殊效果

我方每张卡牌都带有**两个特殊效果**（卡面左上角的两个圆形图标），分别对应我方的减益与增益手段。

![我方卡牌一览]figures/ans_my_fleet.png)

### 增益槽位

| 项目 | 说明 |
| --- | --- |
| **增益槽位** | 每张卡牌 **2 个增益槽位**，对应**白色**与**绿色**两种类型的增益，每种增益每张卡牌**只能选用一个** |
| **槽位复用** | 卡牌上的槽位可放入**变项**，变项分为标准（白）与特殊（绿）两类，正好对应两个槽位 |

### 红色图标 —— 削弱敌方

![减益效果说明]figures/ans_debuff_tooltip.png)

- 红色图标表示**削弱敌方**。
- **如果敌方存在对应的弱点，则直接削弱其战力。**
- 使用方式：需将此单位**放置于具有相应弱点的敌方单位对面**，以降低其战力。
- 每个减益效果都需**指定方向**。

### 绿色图标 —— 属性增强

绿色图标表示**增强我方单位的属性**，共三种，与卡面底部三项属性数值使用同一套图标语言：

| 绿色图标 | 增强属性 | 说明 |
| --- | --- | --- |
| 十字准星（准心） | **火力** | 提升相邻我方单位的火力 |
| 盾牌 | **存活性** | 提升相邻我方单位的存活性 |
| 斜向三点箭头 | **机动性** | 提升相邻我方单位的机动性 |

> **重要区分**：绿色图标增强的是**单位属性**，不涉及任何弱点匹配，也不受「命中 3 次 / 上限 −60%」的限制；红色图标才是需要匹配敌方弱点的减益效果。
> **增益基准值**：每张卡牌的增益效果基准为 **+30%**；装备「团队合作」（标准变项，增益效果 ×2）后可提升至 **+60%**。

### 卡面数值说明

| 位置 | 含义 |
| --- | --- |
| 左上角两个图标 | 两个特殊效果（**红色 = 六类弱点减益**，**绿色 = 三项属性增益**，两套体系互不相通） |
| 右上角数字 | 总战力区间（如 `170–190`）；我方单位带 ±10 浮动，故显示为区间 |
| 底部三项数值 | 火力 / 生存 / 机动，三项之和即总战力 |
| 卡名下方灰条 | 单位生命值槽（3 格，参战一次消耗 1 格） |

## 十一、增益

增益效果可提升战场上**一个相邻单位**的一项参数。每个增益效果会应用于**特定方向（左侧或右侧）**，且只影响该位置上的单位。**单一单位最多可同时拥有两个增益效果。**

| 规则 | 说明 |
| --- | --- |
| **作用对象** | 战场上一个相邻单位的一项参数 |
| **方向限定** | 每个增益效果仅应用于特定方向（左侧或右侧），且只影响该位置上的单位 |
| **数量上限** | 单一单位最多同时拥有 2 个增益效果 |

战斗前请审慎编排队列，以最大化增益与减益效果。战斗前部署单位前先查看敌方单位。

---

## 十二、减益

减益效果可降低敌方战力，但**前提是减益类型必须对应敌方其中一项弱点**。每个减益效果是针对**特定位置：左前方、正前方或右前方**。与弱点不符的减益效果不会产生作用。

| 规则 | 说明 |
| --- | --- |
| **生效前提** | 减益类型必须对应敌方单位的一项弱点 |
| **位置指定** | 左前方 / 正前方 / 右前方 |
| **无效情况** | 与弱点不符的减益效果不会产生任何作用 |

结合第九节：我方舰船对一个方向最多只能有一个减益。**不使用增益时最多 −60%；使用增益（配合「特化训练」减益 ×2）可达 −100%**（1 个 3 级 −60% + 1 个 2 级 −40%）。

---

## 十三、战斗条件

部分关键据点带有**战斗条件**，即会影响战斗的特殊效果。战斗条件可能会**强化敌方单位、削弱您的单位、限制可部署的单位，或停用变项**。

### 三种作用范围

战斗条件按作用范围分为**全域**、**指定**、**区域**三类：

| 类型 | 作用范围 | 是否可移除 |
| --- | --- | --- |
| **全域** | 此关键据点的战斗条件将**带入后续的所有关键据点** | 可被削弱或完全移除 |
| **指定** | 作用于**特定关键据点**，会在地图上标出 | 可被削弱或完全移除 |
| **区域** | **仅应用于此关键据点** | 条件为**永久且无法移除** |

### 全域条件

![全域战斗条件]figures/ans_global_cond.png)

- **每摧毁一个敌方单位可移除 4% 的战斗条件。**
- 此关键据点的战斗条件将带入后续的所有关键据点，可被削弱或完全移除。
- 若在该关卡未能解除，则**后续所有关卡的敌方都会获得增益**（例如：`敌方战力：驱逐舰 +16%`）。

> **含义**：全域条件是一个**跨阶段持续累积**的负面状态。若这一阶段没有把它打掉，后续每个阶段的敌舰都会带着这份增益，滚雪球式放大难度。

### 指定条件

![指定战斗条件]figures/ans_designated.png)

- **每摧毁一个敌方单位可移除 25% 的战斗条件。**
- 影响下个阶段中的**特定关键据点**。
- 会在**地图中显示**对应标记：

## 十七、规则速查表

### 判定关系速记

- **总战力 = 火力 + 存活性 + 机动性 ± 10**，再叠加增益效果与当前生命值影响
- **我方战力浮动**（区间），**敌方战力固定** → 胜率 = 我方区间中「≥ 敌方战力」的档数 ÷ 总档数
- **单条弱点可命中 3 次**达 −60%；不同弱点加算，但一个方向只能挂一个减益 → **无增益上限 −60%，有增益上限 −100%**
- **敌方单位没有增益效果，只有弱点**
- **击败据点敌方单位可削弱或移除该据点产生的条件** → 前期清理顺序决定后续难度
- **全域条件跨阶段累积**（4%/单位），未解除则后续每阶段敌方持续获得增益
- **指定条件** 每摧毁 1 个敌方单位移除 25%，仅作用于特定据点
- **区域条件** 永久且无法移除，仅作用于当前据点
- **卡牌增益基准 +30%**，「团队合作」可使其 ×2 至 +60%
- **一张卡牌在同一阶段内只能参战 1 次**，但不限制其增益效果继续生效
- **敌方卡牌右侧图标 = 胜利后的掉落物**（代币或其他掉落物）
- **卡面底色与敌方强度挂钩**：1 星白色、2 星蓝色、3 星金色/红色；**蓝色比白色高 30 以上战力**

### 变项速查

| 类型 | 名称 | 核心效果 |
| --- | --- | --- |
| 标准 | 炮术训练 / 伤害控制训练 / 方向舵操作训练 | 火力 / 存活性 / 机动性 +20% |
| 标准 | **团队合作** | 增益效果 ×2（+30% → +60%） |
| 标准 | 效率提升 | 进度代币 +10%（仅关底 BOSS 掉落代币） |
| 标准 | **士气打击** | 击败受影响敌方单位时，阶段目标与条件移除计数 **按 2 个计算** |
| 特殊 | **心无旁骛** | 停用所有增益与减益，所有参数 +40% |
| 特殊 | **特化训练** | 减益效果 ×2 |
| 特殊 | **老水手** | 减益**无需对应弱点**即可生效 |
| 特殊 | 快速维修 | 恢复生命值 +2 |
| 特殊 | **势不可挡** | 无视影响己方参数/增益/减益的战斗条件 |

### 易混淆点对照

| 易混点 | 辨析 |
| --- | --- |
| 单位生命值 vs 变项恢复生命值 | 生命值每战自然 −1 格；「快速维修」变项可在战前恢复生命值，属主动补救手段 |
| 区域条件 vs 指定 / 全域条件 | 区域条件固定作用于产生它的据点且**无法移除**；指定 / 全域条件可被击败移除 |
| 变项栏位 vs 战斗条件「停用变项」 | 战斗条件可以使我方变项无法使用；「心无旁骛」则主动停用所有增益减益 |
| 重新开始 vs 放弃 | 放弃保留已获奖励；重新开始会移除奖励、单位与变项并重置 |
| 红色减益 vs 绿色增益 | **两套体系**：红 = 六类弱点减益（需匹配敌方弱点，受 3 次 / −60% 限制）；绿 = 三项属性增益（直接提升相邻友军属性，无匹配与次数限制）。形状与底部属性图标对应的是**绿色**那一套。敌方卡面只有灰色弱点图标，无增益 |
| 我方区间 vs 敌方固定值 | 我方为浮动区间（如 170–190），敌方为固定值（如 91），故胜率是概率而非必然 |
| 弱点上限 2 项 vs 图示 4 环 | 规则为**最多 2 项弱点**；规则卡 10 的 0~3 环仅为示意 |
| 标准变项（白） vs 特殊变项（绿） | 白 = 商店可购买；绿 = 关卡掉落不可购买。工具栏前 6 白、后 5 绿。注意此处「绿」与卡面绿色增益图标**无关联** |
| 浮窗「上/右/左」 vs 规则卡「正前/右前/左前」 | 两套说法**判定一致**，仅表述不同 |
| 「已排派」 vs 生命值归零 | 「已排派」是阶段内已参战限制；生命值归零才是永久不可用，两者不同 |

#### 方向分布统计

我方 30 张卡共 60 个效果槽位，按图标外围黑三角指示的方向分布：

| 方向 | 减益（红） | 增益（绿） | 合计 |
| --- | --- | --- | --- |
| **上**（正前方） | 14 | 0 | 14 |
| **左**（左前方） | 14 | 9 | 23 |
| **右**（右前方） | 14 | 9 | 23 |
| **合计** | 42 | 18 | 60 |

**规律与战术含义：**

1. **减益三方向完全均等（上 / 左 / 右 各 14）** —— 三种站位机会均等，不存在方向偏好。
2. **增益只用「左」与「右」，没有「上」** —— 属性增益必须与友军**并排**才能生效，不可能指向对面方向。左右各 9 个，完全对称。
3. **双减益卡（12 张）的方向组合**：

| 方向组合 | 张数 | 卡牌 |
| --- | --- | --- |
| 左 + 右 | 5 | CORSAIR、AVENGER、HELLCAT、USS北卡罗来纳、USS法拉格特 |
| 上 + 右 | 4 | USS圣地亚哥、USS马布尔黑德、USS休斯、USS密苏里 |
| 上 + 左 | 3 | USS科罗拉多、USS阿拉斯加、USS新奥尔良 |

> **摆放要点**：先看黑三角 —— 减益图标要求该方向上有具备对应弱点的**敌方**单位（上游标「上」= 对面一格，「左 / 右」= 左邻 / 右邻一格）；增益图标要求该方向上有**友军**（只有「左」或「右」，即并排）。

> **编队提示**：单减益卡无变项时上限为 −60%；要打满 −100% 必须用双减益卡，且两个减益分属**不同方向**（12 张双减益卡已天然满足此条件）。绿色增益不受次数限制，可与任一减益自由组合。

### 敌方卡牌的数据展示方式

敌方卡牌的数据为**随机生成**，因此本文档不逐条记录其数值。但敌我卡牌的展示结构基本一致：

| 卡面元素 | 敌方卡牌的展示含义 |
| --- | --- |
| **左上角图标 ×2** | **敌方只有弱点图标，没有增益效果**。灰色图标即该单位的弱点种类 |
| **右上角数值** | 敌方总战力**固定值**（如 91、105、137），不带浮动区间，以红色显示 |
| **右侧图标** | **胜利后的掉落物**（详见下节） |
| **舰体图片 / 卡面底色** | 舰艇涂装照片；底色与敌方强度挂钩（详见下节） |
| **舰名** | 敌方舰名下方无所属部队标注（与我方不同） |

> **关键差异**：敌方卡面左上角**只有灰色弱点图标，不存在增益图标** —— 敌方单位本身没有增益效果。减益只能通过我方卡牌去施加。

敌方卡牌右侧的图标展示的是**胜利后的掉落物**，可能是代币，也可能是其他掉落物：
